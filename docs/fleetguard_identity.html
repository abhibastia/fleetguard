FleetGuard

Identity & authorisation architectureFrozen proposal · 2026-08-31

Four token paths, no shared credentials, no long-lived database passwords. Render carries the console in Phase 1; Databricks Apps takes over in Phase 2.

Design intent as proposed — deliberately not updated. The build reversed this priority (Databricks App shipped as primary; Render kept as fallback) and the actual grants differ from Path B/C below. For the as-built system, see fleetguard_identity_current.html or ARCHITECTURE.md §8a/§8b.
